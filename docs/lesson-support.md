# Отзывы и дополнительные занятия

## Работа преподавателя

1. «Мои группы» → нужная группа → «Отзывы». Выбрать дату прошедшего урока.
2. У каждого ученика заполнить тему, понимание (понял / нужна практика / нужна помощь / отсутствовал), отзыв и при необходимости внутреннюю заметку.
3. «Сохранить и записать к суппорту»: выбрать преподавателя, свободное время и задачу. Запись сразу подтверждается; согласования администратора и суппорта нет.

## Работа суппорта

Любой активный преподаватель может работать суппортом из своего аккаунта.

«Панель суппорта» → «Моя доступность»: дни недели, начало/конец рабочего окна, длительность занятия, количество мест (2–30), кабинет. Для перерыва создать два отдельных окна. Отсутствия закрывают конкретный диапазон дат. Перед отсутствием с существующими записями нужно перенести или отменить записи.

Все занятия бесплатные; индивидуального формата и расчётов оплаты нет. По умолчанию новое окно — 60 минут, 6 мест. Окна подбираются на следующие 28 дней по времени Ташкента. Преподаватель задаёт реальное расписание самостоятельно; пустая доступность не создаёт выдуманных рабочих часов.

«Сегодня» / «Записи» / «История занятий». Флажок «Только занятия, которые провожу я» можно снять, чтобы увидеть направленных учеников. После окончания занятия суппорт отмечает посещение и результат: тема усвоена / нужна ещё помощь. Повторная запись доступна при необходимости или неявке.

Перенос и отмена требуют причину. Перенос атомарный: если новое время недоступно, старая запись остаётся. Прежняя запись сохраняется в истории.

## Ученик и родитель

«Отзывы и помощь»: только свои или связанные дети, публичные отзывы, записи, кабинет, преподаватель и результаты. Внутренние заметки сервер не возвращает. На мобильной веб-версии ученика ссылка также доступна в профиле. В исходниках Expo добавлен аналогичный экран; для установленного Android/iOS приложения необходим новый выпуск приложения.

## Проверки расписания и доставка

- Основные занятия ученика и преподавателя, другие дополнительные занятия, отсутствия, вместимость.
- Общий PostgreSQL advisory lock для записи, переноса, доступности и изменения основного расписания. Проверка мест выполняется внутри транзакции после блокировки; работает между несколькими API-процессами.
- Изменение/восстановление группы и добавление ученика в группу не допускают конфликт с существующей записью.
- У уже созданного занятия сохраняются кабинет, длительность и вместимость при правке регулярной доступности.
- In-app уведомления сохраняются в той же транзакции. Push через outbox и существующую BullMQ очередь с повторами. Напоминание в течение часа до начала. Доставка push при аварии процесса может повториться; запись при этом не дублируется.
- Интерфейс показывает последние 100 отзывов и до 1000 записей начиная с последних 90 дней. Более старые данные не удаляются из базы.

## Проверка разработки

`npm run build`, `npm test -- --runInBand`.

Отдельная интеграционная проверка `scripts/test-support-integration.cjs` разрешена только с DATABASE_URL базы `support_test`. Сначала применить `prisma migrate deploy` к этой изолированной базе. Проверяются конкурентная вместимость, дубликаты, приватность, привязки родителей, конфликты расписания/зачисления, атомарный перенос, отсутствие, результаты, повторная запись, outbox, HTTP роли и валидация.

Миграция `20260923130000_lesson_support` только добавляет новые таблицы, индексы, типы и связи. Старые данные не преобразует и не удаляет.
